- **19 November 2026, the parser's packages installed where the shape check runs.** Done when each job of the project's own workflows that runs the shape check (`core/scripts/shape.mjs`, or the copies check's steps through `core/scripts/checks.mjs copies`) installs the parser's packages before it: `node core/scripts/install.mjs all`, as `core/scripts/steps.mjs` words it (#719). The parser and C#'s grammar now stand in a lock file of their own, `core/.packages/parser/`, installed only where a job names it, since the grammar's package unpacks some 65 MB the reader never runs: every other job installs the first lock alone, as before, and saves those seconds. The core's own workflows a project calls name it where they run the shape check (`copies.yml`), and the sync and the starter kit install both, so a project whose workflows only call the core's has nothing to do, and nor has one with no C#, since the parser starts only on a file of C#. In one whose own job runs the shape check after `node core/scripts/install.mjs` with no name, the check reads no function of C# on the parser, keeps what its baseline lists there and fails nothing by that, saying so as a warning whose mend is that command, until the step names `all`, which can go in ahead of the sync, in a pull request of its own (an older copy's installer, which knows no `all`, fails on it: so add it with the sync, or guard it as `if [ -f core/.packages/parser/package.json ]; then node core/scripts/install.mjs all; else node core/scripts/install.mjs; fi`). The cost: a word in each such step.
